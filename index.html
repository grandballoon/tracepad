Transcribe with Claude

Claude reads each capture's drawing and writes it out as Markdown, with math in LaTeX. The text goes under the capture's timestamp in the exported note, above its image. It uses your own Anthropic API key and costs about a cent or two per capture.

The key stays in this browser and is sent only to Anthropic. Every page on this github.io address shares the browser's storage, so use a key you can revoke, with a spending limit set in the Anthropic Console.
